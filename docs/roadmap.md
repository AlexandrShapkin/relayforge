# Roadmap

1. Offline policy contract, tests, threat model, versioned protocol and CI.
2. Authenticated outbound agent connection, enrolment, revocation and coordinator persistence.
3. Read-only inventory and process inspection with audit logs.
4. Restricted file operations and bounded subprocess execution with explicit approvals.
5. MCP adapter with the same enforced permissions and end-to-end restart tests.
6. Opt-in pilot deployment; only then consider replacing third-party remote access.

Assistant Hub integration is optional; RelayForge must operate independently.
